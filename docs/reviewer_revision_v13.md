# Final reviewer revision V13

V13 changes the inferential scope without changing the fitted primary EEG
predictions. The primary estimand is the equally weighted mean of the 25 paired
CCC increments over five fixed identity blocks. Its interval uses the existing
crossed-bootstrap standard error and a two-sided t critical value with four
degrees of freedom, matching the five block-level aggregation units.

The topology-matched validation contains 300 replicates for each of four signal
families and two task supports. Coverage of the primary uniform mean is
0.980--1.000 across the eight task--scenario combinations. The minimum cellwise
coverage is 0.917, so heatmap cell ranges are descriptive. All uncertainty is
conditional on the fitted predictors; equivalence and retraining uncertainty
are outside the claim.

The block-t validation is deterministically derived from the frozen V12
normal-t rows because both use the same crossed-bootstrap standard error. The
script replaces only the critical value and records the source hash:

```bash
PYTHONPATH=src python scripts/rederive_block_t_validation.py \
  results/block_validation_v12 results/block_t_validation_v13
python scripts/build_final_revision_v13_tables.py
```

The production statistics can be recomputed from the released aggregate
predictions with:

```bash
PYTHONPATH=src python scripts/analyze_exposure_added_value.py \
  /path/to/final_robustness_v9/response \
  /path/to/statistics/block_t \
  --bootstrap 2000 --seed 20260909 --interval-method block_t
```

The earlier percentile, basic, and within-block t-normal results remain
sensitivity checks. The V13 choice was made after the earlier interval
diagnostics failed. It widens intervals and is determined by the aggregation
topology rather than by the signs or magnitudes of the observed EEG effects.

## Post-primary robustness checks

The final artifact also reports three bounded checks that were run after the
primary analysis. A new identity partition plus complete refit changes any
uniform-grid point estimate by at most 0.0135 on Emo and 0.0154 on Urban; all
12 alternative-partition intervals cover zero. Across three EEGNet training
initialization schedules at the four resource corners, all 12 task-setting-run
intervals cover zero and the largest point-estimate span is 0.0097. Fine-tuning
the final LaBraM transformer block and normalization for a residual target gives
-0.0110 [-0.1041, 0.0820] on Emo and -0.0404 [-0.1159, 0.0351] on Urban.

These checks are sensitivity analyses on already inspected datasets. They do
not provide an independent cohort, exhaustive partition or optimizer coverage,
a full 5x5 fine-tuned surface, or a repeated-training confidence interval. The
aggregate evidence is generated by:

```bash
python scripts/build_v13_sensitivity_summary.py \
  paper/generated/final_revision_v13/sensitivity
```
