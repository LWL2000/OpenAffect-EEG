## 最新覆盖分析：方法与完整结果

### 来源和覆盖

EmoEEG-MC 使用 1.0.7 快照，30 名合格用户、42 个刺激、1,260 个可用试次。Urban 使用 ds006850/1.0.0，62 名用户、56 幅图片、3,471 个真实效价试次，不把其他量表复制成效价或唤醒度。一个已确认截断的源记录在预测检查前排除 [@openneuro_ds005540; @openneuro_ds006850]。<!-- evidence: paper/generated/final_closure_v9/verification/verification.json --> Urban 的 dataset_description 声明 CC0，同快照 README 写 CC BY 4.0；保留冲突，不重新发布原始数据或刺激。

用设计种子 20260908 的 SHA-256 顺序将参与者和刺激各分五块。块 b 对角身份对为测试，下一块为验证，其余块为初始群体训练。每身份测试一次不等于所有试次对测试。同刺激标签注入可以使用验证块用户，只有测试用户始终排除于群体拟合，不能把注入后的全部验证身份说成未见。<!-- evidence: src/openaffect_eeg/final_robustness.py; configs/final_robustness_v9.json -->

### 有界训练和预处理

Ridge R1 alpha 网格为 0.1/1/10/100，R2 为 1/10/100/1000。频带功率与 LaBraM 均采用两网格；Emo 历史键 de 实为 channel_log_bandpower，不另称独立 DE 实现。EEGNet 固定 Braindecode 1.2.0，F1=8、D=2、F2=16、dropout=0.25，AdamW weight decay=0.0001，batch size=128，最多 100 轮、patience=15。L1/L2 学习率 0.001/0.0001。验证 MAE 选轮数，训练加验证重拟合。个人校准只改拟合后偏移，不训练网络。<!-- evidence: configs/final_robustness_v9.json; src/openaffect_eeg/final_robustness.py -->

Emo 使用既有 100 Hz 原始试次和十秒 EEGNet 裁剪。Urban 仅 64 个 EEG 通道，物理单位伏，排除 ECG/GSR，平均参考、500 到 100 Hz 多相重采样，使用图片后、评分前的三秒。测试窗口预测在试次内平均。下游学习归一化不读测试或校准。LaBraM 使用记录的 checkpoint、单位与通道适配，上游身份不认证。<!-- evidence: configs/final_robustness_v9.json; scripts/prepare_urban_tensors_v9.py -->

### 已知真值评估器压力测试

在解释 EEG 结果前，我们先在已知构造结果上检验估计器。v6 oracle 套件包含 16 个设置、每项 100 次重复：

| 生成机制 | 记录行为 | 解释边界 |
| --- | --- | --- |
| 仅标签恒等式 | 精确为零 | 仅为代数负对照 |
| 独立噪声 | 16 个设置均无正向检出 | 有限模拟证据，不证明假阳性率严格为零 |
| trial 变化信号 | 检出率 0.85--1.00，覆盖率 0.92--1.00 | 只说明这些设置能检出注入信号 |
| 参与者常数信号 | 校准均值抵消；v6 最低覆盖 0.82 | 暴露有限簇弱点，不作生物或因果解释 |

v7 有限簇研究计划 9,600 次，9,584 次有效，16 次被预设支持规则拒绝。目标 32×24 簇设置下，percentile、basic、t-normal 的覆盖率分别为 0.933、0.930、0.957；刻意缩小到 8×6 簇时，最低值分别为 0.837、0.820、0.940。t-normal 往往更宽，因此只作为敏感性分析，不宣称它普遍校准。<!-- evidence: paper/generated/submission_closure_v11/evaluation_method_validation.json -->

### 规则依据与三态决定

检查器只根据可观测证据给出允许、阻断或不可验证，缺少来源时保留不可验证，不默认通过。

| 规则族 | 必需证据 | 代表性边界 |
| --- | --- | --- |
| 试次血缘 | 每个分区的 trial UID | 同一试次派生窗口重复会阻断试次隔离声明 |
| 身份留出 | 参与者与刺激 UID | 重叠只阻断对应身份声明，不自动否定其他声明 |
| 预处理与选择 | 拟合和选择所用 UID | 缺失来源返回不可验证 |
| 资源匹配 | 每个预测器可访问的标签 | 校准标签不等会阻断 EEG 额外价值声明 |
| 固定测试支持 | 每个比较器的测试哈希 | 测试支持不同会阻断配对比较 |

完整目录逐项记录依据、所需证据、允许/阻断/不可验证示例以及不支持的推论。它不认证数据真实性、上游预训练历史或因果有效性。<!-- evidence: configs/audit_rule_catalog.json -->

## A. 数据来源与试次重建

### A.1 版本固定来源

OpenAffect-EEG 使用以下 OpenNeuro 快照，而不是浮动的“最新版”：MusicEEG `ds002721` 1.0.3、DENS `ds003751` 1.0.6、EmoEEG-MC `ds005540` 1.0.7，以及外部验证 `ds006866` 1.0.0 [@openneuro_ds002721; @openneuro_ds003751; @openneuro_ds005540; @openneuro_ds006866]。每个源文件均通过快照清单、字节数或 annex key 检查；派生 trial 表另记录输入哈希。

4 个数据集共重建 39,642 个试次，涉及 279 名数据集内合格被试，其中 38,369 个试次具有完整且可统一的连续情绪目标。<!-- claims: C39,C40,C41,C42 --> 核心 3 个刺激诱发数据集包含 131 名被试、4,135 个试次和 369 个数据集内合格刺激身份；2,865 个试次进入带完整自我报告的核心监督评测。<!-- claims: C34,C35,C36,C37,C38 -->

### A.2 MusicEEG

MusicEEG 记录参与者聆听电影音乐片段时的 EEG 与八项自我报告 [@daly2020musiceeg]。基准保留 1,240 个任务试次。<!-- evidence: paper/generated/table_benchmark_scope.csv, ds002721 --> 公开事件流没有直接给出规范化音频文件名，当前 `stimulus_uid` 由事件码减去固定偏移后与公开 OSF Set 1 对齐。该映射满足所有试次存在唯一候选码、候选均落入资源编号范围、每个编号同时存在音频与规范评分等检查，但因公开 README、事件说明和早期论文对素材集合的描述并不完全一致，状态被记录为 `audited_inference`，而非 `source_verified`。

MusicEEG OpenNeuro 快照声明 CC0；配套 OSF 音乐资源声明 CC BY 4.0。公开基准不包含音频文件，只发布来源指针、推断状态和分割所需身份元数据。<!-- evidence: cards/datasets/ds002721.md; upstream OpenNeuro and OSF license metadata -->

### A.3 DENS

DENS 使用自然视频诱发情绪，并收集连续维度与类别评分 [@asif2023dens]。事件与行为数据按规范化刺激名称连接，而非按行号连接；缺失行为记录的事件被保留并标为无标签。源 `.set` 头声明的信号长度与多数公开 `.fdt` 文件字节数不一致，完整时间窗只对部分试次可读。特征提取不会补零、循环读取或将缺失二进制样本估算为有效 EEG，而是通过独立可用性掩码记录。365 个有标签试次中仅 162 个具有可用特征，缺失率为 0.5562；7 名被试完全缺失，可用与缺失试次的效价标准化均值差为 0.1895。因此所有 DENS 结果均明确标为 complete-case 分析。<!-- claims: C76,C75,C74,C78,C77 -->

公开事件使用 20 个本地刺激名，但源快照没有 README 所述的 `stimuli/` 与 `code/` 目录，论文所指 AFDI 条目也无法与这些本地身份可靠对应。因此基准仅把公开事件中的本地身份用于组划分，不声称已恢复原始影片文件。DENS 的 `dataset_description.json` 声明 CC0，而仓库 LICENSE 与 README 分别给出 ODbL/DbCL 条款；在矛盾解决前，任何派生发布都按更保守的署名与共享要求处理。<!-- evidence: paper/generated/table_benchmark_scope.csv; cards/datasets/ds003751.md; upstream license files -->

### A.4 EmoEEG-MC

EmoEEG-MC 同时包含视频观看和文本引导想象，适合方向性跨情境评测 [@xu2025emoeeg]。公开行为导出的 `video_name` 对部分参与者被同一错误值重复填充，不能按行位置与 EEG 试次连接。基准只保留可验证全局刺激码的监督子集，其余试次仍留在 provenance 表中，但标签状态设为不可用。可监督子集的情境方向又使用源 EDF 触发类型进行交叉验证。

公开 DE 文件、reorder 数组、CBraMod 与 LaBraM 特征均不进入匿名发布包。基础模型输入仅使用与监督子集一一对应、哈希核验并且数值有限的试次。数据快照声明 CC0；模型代码与 checkpoint 的许可和哈希分别记录，避免把数据、代码和权重视为同一许可对象。

### A.5 ds006866 外部验证

ds006866 研究社会/非社会图片、负性观看、中性观看和认知重评条件下的自我报告与神经生理反应 [@maka2026discrepancy]。基准包含 148 名被试并重建 35,507 个图片呈现试次，其中 35,504 个试次具有完整效价和唤醒度评分。<!-- claims: C43,C44,C33 --> 公开事件表能够恢复实验条件和社会/非社会内容情境，却不包含 trial 级图片身份；EEGLAB 标注也不能补回该字段。因此本数据集支持严格留被试、留内容情境及被试--情境联合留出，但留图片刺激与被试--图片双重留出明确标为 `blocked_by_source_metadata`。

OpenNeuro 快照声明 CC0。相关 OSF 刺激元数据为 CC BY 4.0，但原始图片可能来自具有独立使用约束的素材库；匿名发布包不包含图片或可替代图片分发的媒体索引。<!-- evidence: cards/datasets/ds006866.md; upstream OpenNeuro and OSF license metadata -->

## B. 目标统一与标签边界

MusicEEG 使用 pleasant 与 energetic 自我报告作为效价和唤醒度；DENS、EmoEEG-MC 与 ds006866 使用各自发布的 valence/arousal 字段。MusicEEG、DENS 和 ds006866 的原量表为 1--9，转换为 `(x-1)/8`；EmoEEG-MC 的原量表为 0--7，转换为 `x/7`。原始值、量表名和归一化表达式均保留在 trial 表或结果 provenance 中。<!-- constants-source: src/openaffect_eeg/baselines.py -->

统一连续目标是参与者的试次级自我报告。名义刺激类别、材料规范评分和实验条件均只能作为输入、分层或审计变量，不能替换个体自我报告后仍被称为同一目标。缺少任一连续目标的试次保留元数据，但不进入需要完整效价与唤醒度的监督指标。

## C. 划分协议

### C.1 单因素与乐观对照

完整试次在任何窗口化之前分配。试次随机、留被试和留刺激协议均在每个数据集内使用 70/10/20 的训练、验证、测试比例；小身份集合至少为验证和测试各保留一个组。试次随机只隔离 `trial_uid`，并额外记录被试与刺激在训练和测试间的重叠数量。留被试和留刺激分别要求对应身份交集为零。<!-- constants-source: src/openaffect_eeg/splits.py; scripts/build_strict_splits.py -->

### C.2 双重留出

被试与刺激分别按 60/20/20 分配。仅当两种身份落入同一分区时保留该试次；其余跨分区边被明确标为 `excluded`。这一策略在稀疏被试-刺激图上牺牲部分覆盖，以实现真正的双冷启动。比例在实验前确定，原因是更小的验证身份比例无法为多个种子提供足够验证试次。<!-- constants-source: scripts/build_strict_splits.py; docs/split_protocol.md -->

### C.3 样本支持匹配的身份重叠对照

对每个双重留出种子固定完全相同的测试 trial UID，并保持训练与验证行数分别相等，再从可用训练边中采样，使测试被试和测试刺激均在拟合分区出现。该对照保持测试支持与样本量不变，改变训练侧身份重叠及其图结构；它估计对这一训练组成变化的条件敏感性，不识别身份单因素的因果影响。<!-- constants-source: src/openaffect_eeg/reviewer_controls.py; scripts/build_support_matched_control.py -->

### C.4 跨情境与留数据集

EmoEEG-MC 的方向性迁移先按被试划分，再只允许源情境被试进入训练与验证、目标情境的未见被试进入测试。视频到想象和想象到视频分别运行。情境 holdout 与数据集 holdout 把完整域作为组；当恰有三个域时，训练、验证和测试各持有一个域。<!-- constants-source: src/openaffect_eeg/splits.py; scripts/build_context_transfer_splits.py -->

### C.5 固定种子与分割审计

主表示审计使用 5 个固定种子。<!-- claims: C47 --> 每个 assignment 文件均保存协议、种子、试次角色和对应 audit JSON。构建器检查 trial UID 唯一性、身份字段非空、分区角色合法，以及协议要求隔离的身份交集为零。模型只能在加载冻结 assignment 后应用标签和特征可用性掩码，避免因某种表示缺失而改变身份分配。

### C.6 固定支持的身份暴露响应面

身份可用性不是单一二元变量。当前响应面显式改变两个有标签资源：每名目标参与者的完整校准试次数 (p)，以及每个测试刺激由其他参与者提供的评分数 (s)。每个种子先生成严格的被试--刺激双重留出，再一次性筛选能支持预声明最大剂量的测试被试与刺激；随后所有 ((p,s)) 单元共享同一组哈希固定测试 trial UID。低剂量样本是高剂量样本的确定性子集。

参与者校准试次来自目标参与者在非测试刺激上的记录，从不进入群体模型拟合；它们只估计模型拟合后的已知 ID 平均残差偏移。测试刺激评分来自非测试参与者，可以进入群体模型；每增加一行都会在相同情境内替换一个训练目标最近的 donor，因此群体训练集大小严格不变。该替换控制样本量，但不声称高阶身份图或目标分布获得因果匹配。MusicEEG 公开的规范刺激评分作为独立先验固定，不计入 (s)。当前响应面把目标参与者无标签数据固定为零，也不支持会话无关或跨设备结论。

每个单元由确定性规则编译声明卡：当 (p>0) 时阻断“完全未见参与者”，当 (s>0) 时阻断“未见刺激”，来源无图片 ID 时把刺激结论改为条件级，并始终阻断潜在情绪解耦与因果身份移除。该过程不依赖大语言模型自由生成判断。

## D. EEG 表征与模型

### D.1 透明频谱表示

核心透明表示使用 delta、theta、alpha、beta 和 gamma 频带的 DE 或 Welch 对数功率。全局视图对通道聚合，通道视图保留 channel-by-band 结构。所有标准化参数只在训练分区拟合；Ridge 正则强度以验证 MAE 选择，最终在训练加验证分区重拟合。频带与脑区消融包括单频带、留一频带、单脑区和留一脑区视图。脑区映射属于预测敏感性分析，不被解释为源定位或因果神经解剖结论。

### D.2 CBraMod

官方 CBraMod checkpoint 与同架构随机初始化读取完全相同的 EmoEEG-MC 试次。每个 30 秒、64 通道、200 Hz 试次被组织为一秒 patch，encoder token 在通道和时间维平均池化为 200 维 trial 表征。源代码 commit、checkpoint SHA-256、输入 trial UID 与特征哈希随产物记录。下游只训练相同的预测头，不微调 encoder。<!-- constants-source: src/openaffect_eeg/foundation.py; cards/models/cbramod.md -->

### D.3 LaBraM

LaBraM 使用官方通道位置表和 base checkpoint。30 个一秒 patch 被切成三个 8-patch 窗和一个 6-patch 窗，以 patch 数加权汇总后得到 200 维 trial 表征。预训练专用 mask 与 decoder 头不参与下游特征，官方最终归一化路径保留。随机初始化对照实例化相同架构但不读取 checkpoint。<!-- constants-source: src/openaffect_eeg/labram.py; cards/models/labram.md -->

### D.4 历史紧凑 EEGNet-style 网络

EEGNet 控制直接从 EmoEEG-MC 原始波形训练。输入经抗混叠重采样到 100 Hz；每个 epoch 从完整试次抽取一个确定性 10 秒训练 crop，验证与测试平均三个不重叠 crop 的预测。网络包含时间卷积、深度空间卷积、可分离时间卷积和八维 latent。其用途是检验冻结特征结论是否仅由 DE 或基础模型适配造成，而非进行针对每个数据集的穷尽架构搜索。<!-- constants-source: docs/eegnet_results.md; frozen eegnet_joint_v1.json -->

标准 Braindecode EEGNet 控制另见正文的实现敏感性分析，不能将此历史紧凑网络称为标准实现。

## E. 刺激先验、残差与去偏模型

### E.1 三个预测器

1. `direct_eeg`：EEG 表征直接预测归一化效价与唤醒度。
2. `semantic_stimulus_prior`：对小写 TF--IDF 描述一元/二元词组（最多 1,024 维、sublinear TF）以及名义类别、情境和源刺激强度码拟合 Ridge；每个训练刺激贡献一行群体均值目标，alpha 从 `{0.01, 0.1, 1, 10, 100, 1000}` 中按验证 MAE 选择。强度码不读取参与者评分。
3. `disentangled_prior_plus_eeg_residual`：该名称是冻结结果注册表中的历史键名；已见刺激使用训练侧报告均值，未知刺激使用语义估计，先计算训练期留一试次刺激均值残差，再用 EEG 预测残差并与混合先验相加。它表示算术残差化，不声称潜在状态或因果解耦。<!-- constants-source: scripts/run_disentanglement_baseline.py; src/openaffect_eeg/disentanglement.py -->

所有模型共享同一 assignment、目标和验证规则。先验分支与 EEG 分支分别报告，防止把刺激语义带来的性能归因给脑电。
### E.2 去偏反事实

评估方法包括：训练期刺激中心分量减除；预测与刺激指示变量的条件协方差惩罚；保护响应方向后删除刺激子空间的线性投影；具有梯度反转刺激头的非线性残差网络；以及端到端 EEGNet 对抗版本。每种方法包含零强度设置，且对抗强度、投影维数和训练 epoch 仅根据验证残差 MAE 选择。测试时不使用刺激 ID 进行 EEG 残差预测。

成功标准不是单一 CCC 上升，而是目标性能、MAE、刺激效应量与身份探针共同改善。只降低预测方差、把验证选择推向零强度或在不同种子间方向不一致，均作为负结果报告。

## F. 身份探针

数据集探针在 subject holdout 下使用全局频谱表示；刺激探针在 subject holdout 下于各数据集内部训练，并只评估训练阶段出现过的刺激类；被试探针在 stimulus holdout 下训练，并只评估训练阶段出现过的参与者。该设计分别回答来源域信息能否跨被试、刺激信息能否跨被试、以及参与者信息能否跨刺激迁移。

每个 probe 都保留同表示、同划分、同估计器的训练标签置换对照。balanced accuracy 是主指标，同时报告类别数、机会水平、测试覆盖率和每种子结果。LaBraM 预训练表征的被试身份 balanced accuracy 为 0.9642，随机初始化为 0.1733，均匀机会水平为 0.0333。<!-- claims: C09,C10,C46 --> 十维 DE 特征的数据集身份 balanced accuracy 为 0.8987。<!-- claims: C11 -->

探针只证明身份信息可恢复。为检验其与预测行为的联系，我们在每个留刺激种子上以训练数据估计被试中心差异，经 SVD 得到身份方向，并依次移除 `{0,1,2,4,8,16,24,29}` 个方向；每个秩同时加入等秩 PCA 与带种子的随机正交方向作为一般降维对照。每个点重新拟合相同的语义、直接 EEG、残差和身份 probe，零移除为嵌套对照。该干预可能同时删除身份与真实情绪协变量，因此只解释为对线性可解码身份结构的干预。<!-- constants-source: src/openaffect_eeg/reviewer_controls.py; scripts/run_subject_subspace_intervention.py -->

## G. 统计方法

连续预测报告 valence、arousal 及其 macro CCC、MAE 和 RMSE；身份任务报告 balanced accuracy，并在可用时附 macro-F1。模型比较在完全相同的 trial-level 预测上配对。历史非响应面分析先重采样评测种子，再重采样该种子内完整 held-out identity 簇，双重留出分别重采样被试和刺激因素；这些历史区间采用 2,000 次抽样。它不是本轮响应面的主要估计器。<!-- constants-source: configs/recompute_neurips_ed_v1.yaml; scripts/analyze_paired_predictions.py -->

5 个种子的精确双侧 sign-flip 检验最小可达非零 $p$ 值为 0.0625。<!-- claims: C45,C47 --> 因而，本文使用 bootstrap 区间描述效应估计，把 sign-flip 结果作为有限种子功效说明，而不把传统显著性阈值作为选择性叙事门槛。

本轮身份暴露响应面使用 2,000 次共享参与者×刺激 bootstrap。身份在所有模型、单元和固定种子中共享抽样权重，不能因抽样退化就静默删除某个种子；有效抽样次数另行记录。主要统计为均匀网格上的匹配 EEG 增量平均值。端点效应、按剂量积分的 AUC、首次观测增益和排序变化为不同的次要估计量。五个种子不是五次独立研究复制。<!-- constants-source: configs/competitive_revision_v3.json; src/openaffect_eeg/exposure_statistics.py -->

历史重点审计包括支持匹配的身份重叠、被试子空间端点、LaBraM 留刺激预训练和外部条件先验对比。这些分析在基准开发期间选择，不能称为预注册确认。旧区间是逐比较区间；新版响应面在每个模型的命名增量剂量族内另给同时区间，不扩张为对全文所有比较的统一覆盖。

## H. 补充结果解释

### H.1 预训练的协议依赖性

LaBraM 预训练相对随机初始化在留刺激协议提高 0.0706，95% 区间为 [0.0396, 0.1143]，但在留被试与双重留出中差值为 0.0015 和 -0.0008。<!-- claims: C04,C05,C06,C07,C08 --> 这支持留刺激设置下的额外预测收益，不确立主体不变的额外信息，也不证明其他设置下的收益不存在。

### H.2 匹配对照与被试子空间干预

在测试 trial 与训练/验证行数匹配后，每个种子的测试集包含 32--56 个试次、4--7 名被试和 8 个刺激。恢复训练侧身份重叠使直接 EEG 的宏平均 CCC 相对双重留出提高 0.1511，区间为 [0.0349, 0.2156]；语义先验、混合先验与组合模型分别提高 0.0827、0.0991 和 0.2111，组合区间为 [0.1101, 0.2706]。<!-- claims: C79,C80,C81,C82,C83,C61,C62,C63,C64,C65,C50,C51,C52 --> 最大被试方向移除把身份 balanced accuracy 降至 0.0342，组合模型 CCC 改变量为 -0.0656，交叉区间为 [-0.1070, -0.0272]；相对等秩 PCA 和随机方向的差分分别为 -0.0364 与 -0.0631，区间均不跨零。<!-- claims: C54,C55,C56,C57,C66,C67,C68,C69,C70,C71 -->

语义先验组件消融显示，留刺激时移除名义类别使 CCC 相对完整先验下降 0.3049，区间 [0.2089, 0.3416]；双重留出中的对应下降为 0.4011，区间 [0.2557, 0.4591]。留被试时移除描述文本使 CCC 下降 0.0544，区间 [0.0384, 0.0710]。<!-- claims: C87,C88,C89,C93,C94,C95,C90,C91,C92 --> 双重留出中，情境、强度代码和描述文本的独立贡献分别为 0.0012、-0.0100 和 -0.0129，区间均跨零。<!-- claims: C96,C97,C98,C99,C100,C101,C102,C103,C104 --> 这些是预测组件消融，不是对真实刺激内容的因果干预。

### H.3 外部条件分层

外部数据中，条件先验比 EEG-only 高 0.3457 CCC，95% 区间为 [0.3040, 0.3884]。<!-- claims: C27,C28,C29 --> 条件先验相对通道级组合模型的 MAE 低 0.0134，区间为 [-0.0329, -0.0004]。<!-- claims: C30,C31,C32 --> 条件身份可从 EEG 解码，但条件外残差没有稳定改善任何总体结论。该结果只支持留被试与条件级解释。

### H.4 授权 SEED-V 案例：协议敏感性并非公开数据特有

SEED-V 作为用户已获授权、但不纳入公开基准的独立案例，只发布汇总审计记录，不发布原始 EEG、DE、刺激、试次预测或参与者标识。在原始时间序列的严格被试留出下，Raw 的 macro-F1 为 0.2418，SDSA 为 0.2297，差值为 -0.0121，95% 区间为 [-0.0439, 0.0178]；在更严格的被试-刺激联合留出下，二者分别为 0.1788 与 0.1856，差值为 0.0068，区间为 [-0.0154, 0.0292]。<!-- evidence: paper/generated/seedv_case_study.json -->

同一案例中，严格时序划分下的 PaperStyle F1 为 0.2786，而随机试次式划分达到 0.5922；16 名严格测试参与者中只有 7 人使用 SDSA 后提高。Raw 与 SDSA 的被试身份 probe 分别为 0.7660 和 0.7901。该案例不被解释为某一方法的优劣结论，而是用于说明：协议改变可以远大于表示名称改变，且身份可解码性必须与情绪结果一起报告。<!-- evidence: paper/generated/seedv_case_study.json -->

### H.5 独立 MusicEEG 协议审计：严格泛化、身份信息与评分结构

为检验 EmoEEG-MC 的表征结论是否局限于视觉范式，我们在独立 MusicEEG 上预先固定五个完整 trial 划分，并只发布汇总结果。透明的通道对数频带功率 Ridge 在随机 trial、留被试、留音乐和被试-音乐双重留出下的 macro CCC 分别为 0.1031、0.0175、0.1130 和 0.0227；随机减双重留出的五种子配对差值为 0.0804，种子标准差为 0.0357。留音乐仍保留已知参与者，因此不能替代留被试；这一点在听觉范式中同样成立。<!-- evidence: paper/generated/music_eeg_external_audit_v2.json -->

同一透明表征在未见音乐时识别训练中已见被试的 balanced accuracy 为 0.9995，标签置换为 0.0431，31 类均匀机会水平为 0.0323。相反，在未见被试的已见类别子集上识别音乐身份的 balanced accuracy 为 0.0000，置换为 0.0033；五个种子的测试覆盖率为 78.8--91.3%。这些 probe 只说明对应表征中可获得的身份信息，不证明情绪读出器因果地使用了该信息。<!-- evidence: paper/generated/music_eeg_external_audit_v2.json -->

评分本身也限制解释边界。对同一音乐的其他参与者评分做留一预测时，效价与唤醒度的共识 CCC 分别为 0.1437 和 0.1634（各有 1,123 个受支持评分）。描述性的加性模型中，音乐身份 R-squared 为 0.3579 和 0.3484，高于被试身份的 0.1170 和 0.1782；这既不是重测信度/噪声上限，也不是主观体验的因果方差分解。<!-- evidence: paper/generated/music_eeg_external_audit_v2.json -->

在同一四种协议下，我们将官方冻结 LaBraM 预训练编码器与同架构固定随机初始化比较，所有下游模型均为相同 Ridge 读出器。预训练与随机初始化的 macro CCC（差值）依次为：随机 trial 0.0923 对 0.0191（0.0732），留被试 0.0697 对 -0.0006（0.0703），留音乐 0.0847 对 0.0145（0.0703），双重留出 0.0422 对 0.0085（0.0337）。未见音乐的被试身份 probe 中，预训练为 0.9136，随机为 0.4239，标签置换分别为 0.0313 与 0.0297，接近 31 类机会水平 0.0323。这些点估计表明，预训练编码器在本次听觉范式评测中具有更高的自评预测分数；身份可解码性则是另一个表征属性，不证明预测器利用了身份。该结果不替代 EmoEEG-MC 中的支持匹配对照与表征扰动分析，不证明可迁移的个体情绪已被解耦，也不支持“主体不变情绪表示”的一般化结论。<!-- evidence: paper/generated/music_eeg_external_audit_v2.json -->

## I. 发布与复现边界

匿名公开包包含代码、测试、配置、评测卡、数据卡、Croissant、论文表格源与数值 claim 配置。以下内容明确排除：原始 EEG、源 DE/特征数组、foundation checkpoint、电影、音乐、图片、Office 文件、Git 历史和机器本地路径。

复现模式分为：

- `metadata`：不读取数据，验证基准契约、Croissant 与评测卡。
- `smoke`：使用合成 trial 数据运行分割、基线、probe 和小型注册表。
- `full`：要求用户显式提供已获取的数据根目录，核验冻结输入哈希和重建论文资产。
- `recompute plan/run`：展示或执行原始 trial 构建、特征提取、模型评估、probe、统计与论文编译的有类型依赖图；`--resume` 仅在所有声明输出均存在时跳过步骤。

`full` 验证冻结结果并不等价于重新下载和多日冷启动训练。现有 clean-environment 复现由同一服务器上的隔离环境完成，也不被表述为独立实验室复现。
